## The Problem

Backlogs grow forever. You start with 10 tasks, then 40, then 120 — and none of them are done. Without a forcing function, everything is "someday." There's no clear line between what's shipping now and what's a future idea.

## What Versions Does

Versions cut your project into **bounded milestones**. Each version is a self-contained scope: a name, a deadline, a set of tasks, and a PRD. One version is **active** at a time — that's what you're building right now.

## Key Capabilities

- **Version Timeline** — A horizontal stepper at the top showing your version progression (v1 → v2 → v3). Click any step to jump to it
- **Create with Structure** — Two-step dialog: (1) Name + Description, (2) PRD document, Goals, and Deadline
- **Active Version** — One version is active at a time. Dashboard, Growth, and Build all scope to it by default
- **PRD Editor** — A full-width markdown textarea inside each version for writing product requirements. Save inline, edit anytime
- **Progress Stats** — Per-version completed task count, in-progress count, and a visual progress bar
- **Radial Progress Chart** — A dark green card with a half-circle radial showing completed vs total tasks for the selected version
- **People & Assignments** — See who's working on what within a version. Per-assignee completion stats with mini progress bars
- **Reorder** — Move versions up or down to reflect your actual roadmap sequence
- **Tab Navigation** — Quick horizontal tabs for switching between versions when you have many

## Why It Matters

Versions are the philosophy of SaaSfollo. Instead of an infinite backlog, you answer: **"What ships in this version?"** That constraint — a name, a deadline, a bounded scope — is what turns ideas into shipped products.

When v1 is done, you mark it complete and move to v2. Clean slate, fresh focus. No baggage from the last cycle.
