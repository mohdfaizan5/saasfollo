## The Problem

Product thinking happens in scattered places — Google Docs, Apple Notes, random .txt files, Slack messages to yourself. When you need to revisit an ICP definition or meeting notes from last week, you can't find them because they don't live with the project.

## What Notes Does

Notes is a **block-based editor** inside your project. Write product requirements, brainstorm ideas, define your ICP, or take meeting notes — all saved alongside your tasks and versions.

## Key Capabilities

- **Block Editor** — Powered by Editor.js with Notion-style block types:
  - Paragraphs, Headers (H1–H4), Lists, Checklists, Code blocks, Quotes, Inline Code
  - Slash commands — type "/" to insert any block type
  - Inline formatting toolbar for bold, italic, links
- **5 Starter Templates:**
  - **Ideal Customer Profile** — Target role, core pain, alternatives, switching reason
  - **Blank Note** — Empty starting point
  - **Meeting Notes** — Date, attendees, agenda, discussion, action items
  - **Product Requirements** — Overview, problem statement, goals/metrics, user stories, requirements
  - **Brainstorm** — Topic, ideas, promising concepts, next actions
- **Auto-Save** — Content saves every 10 seconds automatically. No "forgot to save" moments
- **Manual Save** — Save button for immediate persistence when you want certainty
- **Masonry Grid** — Notes display as cards in a masonry layout with title, preview text, and last-updated timestamp
- **Quick Create** — One-click creation from any template. Title dialog for new blank notes
- **Read-Only Mode** — Readers see notes with a "View Only" badge. No accidental edits

## Why It Matters

Your product thinking stays with your product. The ICP doc is next to the tasks. The brainstorm is next to the version PRD. No app-switching, no link-hunting. Write it, save it, find it — all inside the project.
