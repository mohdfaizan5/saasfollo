## The Problem

Solo founders ship work every day but never know if they're actually making progress. Metrics live in spreadsheets, task boards, and analytics tools — none of them talk to each other. You finish a week and think *"Did I move the needle or just stay busy?"*

## What Dashboard Does

Dashboard is the first screen you see when you open a project. It answers one question: **"How healthy is my project right now?"**

Everything is scoped to your **active version** — so you're always measuring against what you committed to ship, not everything in the backlog.

## Key Capabilities

- **Time Range Toggle** — Switch between Today, This Week, or This Month to see stats for that window
- **Active Version Card** — Shows your current version name, deadline, and how much time is left (e.g., "3 weeks left")
- **Task Stats** — Completed tasks and created tasks in the selected range, with comparison to the previous period
- **Velocity** — Tasks completed per day. If you're completing 2.5 tasks/day with 15 open, Dashboard tells you the finish line is ~6 days away
- **Completion Gauge** — A radial progress ring showing how far along your active version is
- **Contributors Panel** — Who did what. Each contributor's completed tasks, count, and contribution percentage
- **Growth Pulse** — A snapshot of your growth sprint: log volume, active activities, and stuck activities. Links directly to the Growth page
- **4 Charts:**
  - Created vs Completed — stacked area chart to spot if you're adding faster than finishing
  - Status Breakdown — bar chart of Now / Next / Later / Done
  - Growth Log Trend — daily growth activity over time
  - Version Completion — radial bar showing done vs total

## Why It Matters

You stop guessing. Open Dashboard, see the numbers. If velocity is dropping, you know before it becomes a problem. If contributors are imbalanced, you see it. If growth is stalling, there's a signal right there.

One screen. No context-switching.
